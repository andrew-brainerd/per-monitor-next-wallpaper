# Per-Monitor Next Desktop Background — Spec & Status

Windhawk mod (`per-monitor-next-wallpaper.wh.cpp`) for `explorer.exe`, x64 only.

## Goals

1. **Next desktop background** (desktop right-click menu) changes the wallpaper
   on the monitor that was right-clicked, instead of Windows' round-robin.
2. **Sync desktop backgrounds** menu item puts the same image on all monitors.
3. Setting `nextMode`: `clicked` (default) or `all` (Next changes every monitor
   to one new image). Setting `syncMenuItem` (default on) shows the Sync item.
4. The slideshow must stay on, keeping Windows' shuffle, history and settings.

## Design

### Next on the clicked monitor (Windows' own advance)

- Hook `CSlideshowContextMenu::InvokeCommand` (stobject.dll, CLSID
  `{0bf754aa-c967-445c-ab3d-d8fda9bae7ef}`, vtable slots 3/4/5 =
  QueryContextMenu/InvokeCommand/GetCommandString). On Next, store
  `MonitorFromPoint(click point)` as the pending monitor (15 s timeout), then
  call the original so Windows advances normally.
- Hook shell32 `CMultimonWallpaperState::_GetNextMonitor`. For modes 0–2
  (picking a monitor for a new image), take the pending monitor and return its
  index (`GetCount` / `GetMonitorAt`). Mode 3 is a "last updated" lookup
  (`GetLastUpdatedImage`) and is passed through untouched.
- Hook shell32 `CMultimonWallpaperState::DoesAnyMonitorNeedAnImage`. Its only
  caller is the loop in the slideshow worker's `_SendImages` that keeps handing
  out images while any monitor is flagged as needing one. After a redirected
  pick (thread-local `t_redirected`), return false once so only the clicked
  monitor changes.
- All menu hooks check `*(void**)self == g_slideshowMenuVtable`.
- Windows 11 menu only shows added items that have a verb, so
  `GetCommandString` returns `SyncDesktopBackgrounds` for the Sync item.

### Sync and "all monitors" mode (set, then re-arm)

- One MTA worker thread (stop event + auto-reset work event).
- `IDesktopWallpaper::SetWallpaper` per monitor turns the slideshow off, so
  afterwards `SetSlideshow(folder array)` turns it back on (keeps current
  images); restore options if they changed.
- Before changing anything, save `rearmPending`/`rearmPaths` with
  `Wh_SetValue`; on load `RecoverInterruptedChange()` re-arms if a change was
  interrupted.
- `CollectImages` (all-monitors mode only) skips junctions/symlinks but enters
  OneDrive folders.

### Useful facts

- `IDesktopWallpaper::AdvanceSlideshow` returns E_NOTIMPL for a non-NULL
  monitor or DSD_BACKWARD — that's why the shell32 hooks exist.
- Symbol names for Windhawk omit `__ptr64` and keep a trailing space after
  `const`, e.g. `public: bool __cdecl
  CMultimonWallpaperState::DoesAnyMonitorNeedAnImage(void)const `.
- shell32 flow: `CDesktopWallpaper::AdvanceSlideshow` → `CSlideshow::Tick` →
  `CSlideshowWorker::TickWorkItem` → `_SendImages` →
  `CMultimonWallpaperState::UpdateNextMonitor` → `_GetNextMonitor` (tries
  modes 0, 1, 2 until one returns ≥ 0).
